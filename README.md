# 贝贝家外贸复制系统

本项目用于生成海外销售渠道搜索任务、读取客户结果，并辅助通过公开联系方式开展业务联系。

系统按“国家 + 城市 + 产品”探索销售渠道。城市必填，HS Code 选填；除大型连锁、小型卖场、进口经销商和海外网店外，还可通过目标客户提示词寻找整装设计师、室内设计工作室、装修公司、工程承包商等自定义渠道。

页面生成 `$find-target-buyers` 调用参数；真实数据挖掘、联系人查找、证据核验与结构化 JSON 输出由同名 Skill 完成。对公开核验的企业 WhatsApp，Skill 会同时生成基于该企业业务证据的英文首条招呼，页面可调用本机 WhatsApp 预填消息。
